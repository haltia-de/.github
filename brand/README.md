# Знак Haltia

**Знак** — карельский ромб с «рогами», оберег с вышитых полотенец, цвета
рябины (тоже оберег в северной традиции), с янтарным огоньком в сердце:
«в доме горит огонь, а дом хранят». Рога симметричны: закрученные в одну сторону
крючки читались бы как вращающийся знак.

| Файл | Где |
|---|---|
| `haltia.svg` | знак среды Haltia: профиль, иконки пакетов, сайт |
| `haltia-avatar-500.png` | аватар организации на GitHub (500×500) |
| `haltia-small.svg` | 16–24 px: ромб без рогов |
| `pertin-haltia-tablet.svg`, `-tablet-portrait.svg`, `-monitor.svg`, `-laptop.svg` | знак сборки Pertin Haltia: оберег на экране устройства этой сборки |
| `pertin-haltia-tablet-splash.png` | заставка загрузки B8000-H (рисует `linux-port/initramfs/splash.py`) |

**Шрифт:** [Golos Text](https://github.com/google/fonts/tree/main/ofl/golostext)
(ParaType, SIL Open Font License 1.1), начертание Medium для надписи «Haltia».

**Цвета:**

| | |
|---|---|
| рябина (оберег) | `#D9542B` |
| янтарь (огонёк) | `#F6BB3C` |
| лён (корпус устройства, надпись) | `#EEE8DC` |
| ночь (фон) | `#1E1D1B` |

Рябина — только для знака и бренда: в интерфейсе красно-оранжевый читается
как «ошибка». Контраст рябины с ночью 4.2, со светлым фоном 3.5 (WCAG для
знака — от 3). Жёлтый янтарь одним цветом знака не делается: он почти
совпадает с жёлтым Binance (`#F3BA2F`).

## Иконки программ

Все программы Haltia — в одном стиле (эскизы — `icons/`):

- сетка 128 × 128, **плашка** — скруглённый квадрат 112 × 112 с отступом 8 и
  радиусом 26, залитая цветом программы;
- на плашке — **простой символ** без мелочей светлым цветом `#F7F3EA`; на
  светлых плашках (Музыка, Блокнот) символ тёмный `#1E1D1B` или в цвет плашки;
- без теней, градиентов, текста и шрифтов: иконка должна читаться в 32 px;
- символ занимает примерно середину плашки, одинаково по весу у всех.

Цвет — метка программы, по нему её находят:

Рябину `#D9542B` иконки не берут: она только для знака. Firefox остаётся со
своим знаком (товарный знак Mozilla). Рабочие кнопки в окнах — синие, как
привыкли; красное в интерфейсе — только ошибка.
