# Знак Haltia

**Знак** — карельский ромб с «рогами», оберег с вышитых полотенец: светлый
ромб-огонёк в янтарном ромбе. Рога симметричны: закрученные в одну сторону
крючки читались бы как вращающийся знак.

| Файл | Где |
|---|---|
| `haltia.svg` | знак среды Haltia: профиль, иконки пакетов, сайт |
| `haltia-small.svg` | 16–24 px: ромб без рогов |
| `pertin-haltia-tablet.svg`, `-tablet-portrait.svg`, `-monitor.svg`, `-laptop.svg` | знак сборки Pertin Haltia: оберег на экране устройства этой сборки |
| `pertin-haltia-tablet-splash.png` | заставка загрузки B8000-H (рисует `linux-port/initramfs/splash.py`) |

**Шрифт:** [Golos Text](https://github.com/google/fonts/tree/main/ofl/golostext)
(ParaType, SIL Open Font License 1.1), начертание Medium для надписи «Haltia».

**Цвета:**

| | |
|---|---|
| янтарь (знак, акцент) | `#F6BB3C` |
| лён (светлое, огонёк) | `#EEE8DC` |
| ночь (фон) | `#1E1D1B` |

На светлом фоне янтарь бледнеет: там знак ставится на тёмную плашку, как в
этих файлах.
